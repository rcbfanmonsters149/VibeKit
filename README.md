# VibeKit ⚡

A curated collection and workbench for frontend aesthetics, design components, color palettes, and vibecoding workflows.

## Features

- 🎨 **Visual Aesthetics Showcase**: Explore curated frontend designs and design styles.
- 🧩 **Interactive Component Studio**: Live previews, responsive canvas, and code snippets.
- 🎭 **Palette Explorer**: Discover color palettes and themes.
- ⚡ **Built with Next.js 15 & Tailwind CSS**: Powered by React 19, Framer Motion, and Lucide icons.

## Getting Started

### Prerequisites

- Node.js 18+ installed

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build

```bash
npm run build
```

## 🚀 Deploy on Vercel

The fastest way to deploy VibeKit is with [Vercel](https://vercel.com):

1. **Push to GitHub**: Make sure your repository is pushed to GitHub.
2. **Import into Vercel**:
   - Go to [vercel.com/new](https://vercel.com/new).
   - Select your `VibeKit` repository.
   - Framework preset will automatically be detected as **Next.js**.
   - No custom environment variables are required.
3. **Click Deploy**: Vercel will run `npm run build` and provision your globally distributed edge deployment.
